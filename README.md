# Ultimate-asm-compiler  
Универсальный компиятор ассеблера для risk-v совместимых процессоров, основанный на префабах которые описывают основные парраметры процессора:
Разрядность,Регистровый файл(мнемоники),ISA,Длинну машинного слова,Порядок байт,кодирование инструкций
Предостовляя быстрое создание aссемблера
# Описание основного языка 
### Синтаксис
Строка = инструкция + возможный комментарий не учитывая табуляцию. Аргументы разделяются через пробел
```asembly
;{ op } { arg1 } { arg2 } ...... ; коментарий
jmp _MAIN
    jmp _MAIN
        jmp _MAIN ; start

```
При возможности не оставляйте пустые строки, либо не используйте табуляции
``\t\t`` - плохо
---
### Представления чисел
Функция get_number(str) принимает числовой аргумент, возврашая число 

| **синтаксис** | **описание**      |     **особенности**      |
|:-------------:|-------------------|:------------------------:|
|               | целое десятичное  |            -             |
|      0x       | шестнадцатиричное |            -             |
|      0b       | двоичное          |            -             |
|      0o       | восьмиричное      |            -             |
|       f       | float             | если длинна слова >= 32b |
|    "", ''     | символ ASCII      |    только один символ    |
|       :       | метка             |            -             |
|      []       | простое выражение |         см. ниже         |
### Выражения
Выражения записываются в `[]` без пробелов.
```
[{операнд}{оператор}{операнд}...]
```
Длинна не ограниченна. Выполняются последовательно, без приоритетов.
#### Операторы:
| Оператор | Описание        |
|:--------:|-----------------|
| `+`      | сложение        |
| `-`      | вычитание       |
| `&`      | побитовое AND   |
| `\|`     | побитовое OR    |
| `^`      | побитовое XOR   |
| `<`      | сдвиг влево     |
| `>`      | сдвиг вправо    |

```assembly
#define _RAM 0x8000
#define _VAR 0xCF

#define VAR_ADRESS [_RAM+_VAR]; 0x80CF
```

## Функции предпросессора
### `data=` `Метка` `val,val,val .....` до 16 шт - Сохранение в памяти
```assembly
data= msg "H","E","L","L","O",0x00
```
### `#define` `Метка` `значение` - Ручное добавление метки 
```assembly
#define _RAM 0x0000
#define _data 0x8000
```
### `fn:` `метка` - метка программы
```assembly
fn: main
    jmp _MAIN
```
### `:` `Адресс` - Метка адреса

``` asembly
: 0x8000
    data= hello_msng "H","E","L","L","O",0x00
```

# Описание процессора
Процессоры хранятся в поддиректории `processors` и являются обычными модулями `.py` основа которого класс `parram`. 
```python
class parram:
    def __init__(self):
        self.name = "exemple"
        self.mem_len = 0xFFFF 
        self.max_number = 0xFF
        self.width = 8 
        self.insruction_len = 4 
        self.order = 'big-endian'
        self.REGISTERS = {}
        self.COMMANDS = {
            'DATA=': 'spec',    
            '#define': 'spec', 
            'fn:': 'spec',      
            ':': 'spec'      
        }
        self.LEN = {
            "data=" : 1,        
            "#define" : 1,      
            "fn:" : 1,        
            ":" : 1 
        }
        self.functions = {}
        self.Labels = {}

```

# Парраметры `__init__`
## Числовые
| парраметр             | описание                            |
|-----------------------|-------------------------------------|
| `self.mem_len`        | Адресное пространство(слов)         |
| `self.max_number`     | Максимальное обрабатываемое число   |
| `self.width`          | Разрядность слова                   |
| `self.insruction_len` | Минимальная длинна инструкции(слов) |
---
## Cтроковые
| парраметр    | описание                                      |
|--------------|-----------------------------------------------|
| `self.order` | Порядок Слов `little-endian` или `big-endian` |
| `self.name`  | Имя процессора                                |
---
## Словари
### `self.REGISTERS` Регистровый файл 
 ```python
#Регистр : Индекс
REGISTERS = {
    "r0" : 0,
    "r1" : 1,
}

 ```
Считается что в каждый регистр шириной ровно в одно слово. Используется функцией `get_register(name)` возвращает индекс или `REGISTER_INVALID`

---
### `self.COMMANDS` ISA
Показывает как кодируются инструкции парой Инструкция : eval формула
