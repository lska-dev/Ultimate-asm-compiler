# Ultimate-asm-compiler
Universal assembly compiler for RISC-V compatible processors, based on prefabs that describe the core processor parameters: 
bit width, register file (mnemonics), ISA, machine word length, byte order, instruction encoding. 
Enables rapid creation of assemblers.

Универсальный компиятор ассеблера для risk-v совместимых процессоров, основанный на префабах которые описывают основные парраметры процессора:
Разрядность,Регистровый файл(мнемоники),ISA,Длинну машинного слова,Порядок байт,кодирование инструкций
Предостовляя быстрое создание Ассемблера
